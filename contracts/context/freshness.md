# Freshness and conflicts

Check freshness before accepting work, resuming an interrupted task, writing shared facts and declaring completion.

A task is usable only when its expiry has not passed and its objective, acceptance criteria, referenced demand Context and dependencies remain understandable. Mark information `stale` when this cannot be demonstrated.

For a conflict, record the paths, factual difference, impact, reversible handling and required reviewer. Continue only work independent of the disputed fact.
