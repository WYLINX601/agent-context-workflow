# Authority

When sources disagree, use this order:

1. Explicit human approval and the current task instruction.
2. The selected live artifact.
3. The current task manifest and its acceptance criteria.
4. Approved demand decisions and demand Context.
5. Project Context.
6. Runtime memory, sessions, drafts and generated outputs.

Do not choose between same-level conflicts by timestamp alone. Preserve the conflicting evidence, describe the impact, and request a decision from the responsible human.
